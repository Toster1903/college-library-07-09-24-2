# УП4. Каркас и консольное меню

Проект содержит main.cpp, LibraryItem.h/.cpp, Book.h/.cpp, Magazine.h/.cpp, Reader.h/.cpp, Loan.h/.cpp, Library.h/.cpp, Input.h/.cpp.

В main.cpp цикл показывает меню, readInt получает команду, switch вызывает отдельный метод Library. После операции цикл повторяется. Команда 0 вызывает exitProgram и завершает программу. Ветка default выводит «Неизвестная команда».

| Команда | Отдельная функция |
|---|---|
| 1 | addBook |
| 2 | addMagazine |
| 3 | registerReader |
| 4 | searchItem |
| 5 | lendItem |
| 6 | returnItem |
| 7 | printAvailable |
| 8 | printActiveLoans |
| 9 | save |
| 0 | exitProgram |

В итоговой версии заглушки заменены работающими операциями. Для сборки: make. Для запуска: ./library.
