# УП5. Ввод, разбор строк и тестирование

Объявления находятся в Input.h, определения в Input.cpp.

- readInt(prompt,min,max) читает строку, проверяет целое число и диапазон, при ошибке повторяет запрос. Числа с буквами и дроби отклоняются.
- readNonEmpty(prompt) убирает пробелы по краям, отклоняет пустую строку и символ ;.
- split(line,';') делит строку на поля, сохраняя пустые поля для последующей проверки.
- parseInt проверяет числа при загрузке файлов.
- Library::isUniqueId проверяет номера изданий, isUniqueTicket проверяет билеты. Номер выдачи назначается как максимальный существующий номер плюс 1.

| Ввод | Контекст | Ожидаемый результат |
|---|---|---|
| 0 | Меню | Выход |
| 0 | ID | Повторный запрос |
| 1 | Меню | Добавление книги |
| 9 | Меню | Сохранение |
| 10 | Меню | «Неизвестная команда» |
| Пустая строка | Число или название | Повторный запрос |
| Повторный id | Добавление книги или журнала | Отказ |

Автоматические проверки: make test. Тесты работают во временных папках, не меняют пользовательские файлы. Проверяются полный цикл выдачи, сохранение и загрузка, повторная выдача и возврат, неверный ввод, дубликаты, границы года и месяца, повреждённые файлы. Результат текущего запуска записан в tests/RESULTS.md.
