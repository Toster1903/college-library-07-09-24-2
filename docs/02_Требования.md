# УП2. Требования и контрольные сценарии

| № | Функция | Результат |
|---|---|---|
| 1 | Добавить книгу | Новая книга в коллекции |
| 2 | Добавить журнал | Новый журнал в коллекции |
| 3 | Зарегистрировать читателя | Новый читатель |
| 4 | Найти издание по id | Информация или сообщение об отсутствии |
| 5 | Выдать издание | Активная выдача, издание занято |
| 6 | Вернуть издание | Выдача закрыта, издание доступно |
| 7 | Вывести доступные издания | Список доступных книг и журналов |
| 8 | Вывести активные выдачи | Список незакрытых выдач |
| 9 | Сохранить | Запись трёх файлов |

Дополнительная команда 0 завершает работу. Неизвестная команда выводит «Неизвестная команда».

| № | Правило проверки |
|---|---|
| 1 | id изданий и выдач уникальны в своих коллекциях, ticket читателя уникален. Номера положительные |
| 2 | year от 1500 до 2100 включительно |
| 3 | month от 1 до 12 включительно |
| 4 | Нельзя выдать занятое издание или создать выдачу для отсутствующего читателя либо издания |
| 5 | Нельзя вернуть уже возвращённое издание или неизвестную выдачу |

Текстовые поля непустые и не содержат разделитель ;. Номер выпуска положительный.

| Сценарий | Предусловие | Действия | Ожидаемый результат |
|---|---|---|---|
| Успешная выдача | Книга id=1 доступна, читатель ticket=10 зарегистрирован | Команда 5, билет 10, id 1 | Выдача №1 активна, книга недоступна |
| Отказ повторной выдачи | Выдача №1 активна | Команда 5, билет 10, id 1 | «Издание уже выдано», новая выдача не создаётся |
| Успешный возврат | Выдача №1 активна | Команда 6, номер выдачи 1 | Выдача неактивна, книга снова доступна |
